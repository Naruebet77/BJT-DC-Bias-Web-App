# Reflection — BJT DC Bias Web App

ENG29 2121 · Lab 02 · Voltage-Divider Bias

## สิ่งที่เรียนรู้

1. **Frontend / Backend แยกกันได้ชัด** — `templates/index.html` เป็นแค่เทมเพลตที่ Flask render ไม่มีสมการฟิสิกส์อยู่เลย สมการทั้งหมดอยู่ใน `dc_bias.py` ซึ่งไม่รู้จัก Flask หรือ HTML ทำให้ทดสอบสมการได้เองโดยไม่ต้องรันเว็บ
2. **HTTP รอบเดียวแสดงผลได้** — `POST /calculate` คืนหน้าเดียวกันพร้อมผลลัพธ์หรือข้อความ error ไม่ต้อง redirect ทำให้ทดสอบด้วย Flask test client ได้ง่าย
3. **หน่วยต้องชัดเจนทุกช่อง** — อินพุตตัวต้านทานรับเป็น Ω แล้วแสดง kΩ กำกับในผลลัพธ์ ป้องกันความสับสนระหว่างค่าที่ป้อนกับค่าที่คำนวณ
4. **แบบจำลองต้องบอกตัวเองว่าใช้ไม่ได้เมื่อไหร่** — การเตือนในกรณี Cutoff (VTH ≤ VBE) และ Saturation (VCE ≤ 0.2 V) สำคัญไม่แพ้ตัวเลข เพราะแบบจำลอง Forward-Active ใช้ไม่ได้นอกเขตนั้น

## ข้อจำกัดที่พบ

- β และ VBE ถือว่าคงที่ ตามที่ใบแล็บกำหนดสำหรับ Lab 2 จึงไม่ครอบคลุมกรณีอุณหภูมิเปลี่ยนหรือ Early Effect
- ยังไม่รองรับ Bias type อื่น (Fixed Bias, Emitter Bias) หรือไตรภาคอื่น (FET)
- ยังไม่มี AC analysis, Bode plot, หรือ Transient ตามที่ภาพเป้าหมายปลายภาคแสดงไว้ จะเพิ่มในสัปดาห์ถัดไป
- รันได้เฉพาะ localhost เครื่องพัฒนา ไม่เปิดสู่เครือข่ายสาธารณะ

## สิ่งที่ควรปรับปรุงใน Lab ถัดไป
